Remarks

Validates the Address of the mailbox as an SMTP address as defined by rfc5321. The display name and the route of the mailbox are not validated.

  Note

The address is validated exactly as it was parsed or set. An internationalized domain (such as grå.example.com) is reported as NonAscii. To validate the form of the address that would be used in an SMTP transaction that does not use the SMTPUTF8 extension, validate the string returned by GetAddress(Boolean) with a value of instead.
