Remarks

Commits a stream returned by CreateStream(NullableUniqueId, String, Int64, Int64).

This method is called only after both the message data has successfully been written to the stream returned by CreateStream(NullableUniqueId, String, Int64, Int64) and a UniqueId has been obtained for the associated message.

For subclasses implementing caching, this method should be used for committing the stream to their cache.

  Note

Subclass implementations may take advantage of the fact that CommitStream(Stream, UniqueId, String, Int64, Int64) allows returning a new Stream reference if they move a file on the file system and wish to return a new FileStream based on the new path, for example.
