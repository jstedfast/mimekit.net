public enum RtfComplianceViolation

Remarks

An enumeration of the ways in which a Rich Text Format (RTF) document may deviate from the Microsoft Rich Text Format (RTF) Specification, Version 1.9.1, as reported to an IRtfComplianceLogger.

A handful of members do not describe a defect in the document at all, but rather a limit that the document exceeded. They are reported the same way so that a consumer can tell that some of the content was not processed.

Members

None 0 No violation.
MissingRtfHeader 1 The document did not begin with the {\rtf header.
UnbalancedGroupEnd 2 A group end (}) did not match any group start.
ContentAfterDocument 3 Content followed the end of the outermost group.
TruncatedStream 4 The document ended before all of its groups were closed.
KeywordTooLong 5 A control word was longer than 32 letters.
InvalidParameter 6 A control word had a malformed or out-of-range numeric parameter.
InvalidHexEscape 7 A \' escape was not followed by two hexadecimal digits.
UnescapedEightBitCharacter 8 The document contained a non-ASCII character that was not escaped.
UnpairedSurrogate 9 A \uN control word specified one half of a UTF-16 surrogate pair without the other.
UnsupportedCodePage 10 A code page specified by the document could not be resolved.
UndefinedFont 11 A \fN control word referred to a font that was not defined in the font table.
UndefinedColor 12 A \cfN or \cbN control word referred to a color that was not defined in the color table.
InvalidFontSize 13 A \fsN control word specified a font size that was not positive or was too large.
FieldInstructionTooLong 14 A field instruction was longer than the maximum length that is examined.
FontTableLimitExceeded 15 The font table contained more entries than the configured limit.
ColorTableLimitExceeded 16 The color table contained more entries than the configured limit.
GroupDepthLimitExceeded 17 Groups that change the formatting state were nested more deeply than the configured limit.
TooManyComplianceIssues 2,147,483,647 Too many compliance issues were detected and the remainder were suppressed.
