Remarks

Describes a single parse error, as defined by the tokenization section of the HTML Living Standard, along with the location within the document where it was detected.

New properties may be added to this structure in future versions of MimeKit in order to provide richer context about a violation. For that reason, always construct instances using one of the available constructors rather than relying on the default value.

The default value of this structure has a Violation of None, which is never reported and cannot be constructed, so it may be used to detect an uninitialized instance.
