ChainedStream Class

A chained stream.

Definition

Namespace: MimeKit.IO
Assembly: MimeKit.Core (in MimeKit.Core.dll) Version: 5.0.0
C#
public class ChainedStream : Stream
Inheritance
Object    MarshalByRefObject    Stream    ChainedStream

Remarks

Chains multiple streams together such that reading or writing beyond the end of one stream spills over into the next stream in the chain. The idea is to make it appear is if the chain of streams is all one continuous stream.
