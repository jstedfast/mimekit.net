Get the error response codes received by the command.

public IReadOnlyList<ImapResponseCode> ResponseCodes { get; }

Property Value

IReadOnlyListImapResponseCode
The error response codes. If the server did not include any error response codes, the list is empty.

Remarks

Gets the error response codes (such as [OVERQUOTA] or [TRYCREATE]) that the server included in the tagged and untagged responses to the command, in the order that they were received.

Response codes are defined by various IMAP specifications such as rfc3501 and rfc5530. Response codes that carry additional data are represented by subclasses of ImapResponseCode, such as BadUrlResponseCode.
