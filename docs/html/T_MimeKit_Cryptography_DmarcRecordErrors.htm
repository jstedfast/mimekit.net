DmarcRecordErrors Enumeration

The syntax errors found while parsing a DMARC Policy Record.

Definition

Namespace: MimeKit.Cryptography
Assembly: MimeKit.Cryptography (in MimeKit.Cryptography.dll) Version: 5.0.0
C#
[FlagsAttribute]
public enum DmarcRecordErrors

Remarks

As required by RFC 9989, Section 4.8, syntax errors in a DMARC Policy Record are discarded in favor of default values. These flags record which errors were discarded, so that they can be logged or included in reports.
