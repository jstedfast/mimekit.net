Remarks

Opens a stream that encodes the RTF that is written to it as a compressed RTF value of a Binary property, such as RtfCompressed, as defined by [MS-OXRTFCP].

If compress is , the RTF is compressed using Compressed; otherwise, it is stored using Uncompressed.

The value is completed when the stream is disposed. No other value or property may be written until then.

InvalidOperationException
