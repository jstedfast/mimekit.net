ImapResponseCodeType Enumeration

An enumeration of the known IMAP response codes.

public enum ImapResponseCodeType

Remarks

IMAP response codes are the bracketed atoms (such as [TRYCREATE]) that a server may include in a status response (OK, NO, BAD, PREAUTH or BYE) in order to provide additional, machine-readable information about the response.

Response codes that are not recognized by MailKit are represented by Unknown; the original atom is still available via the Atom property.
