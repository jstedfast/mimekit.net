public enum MimeComplianceSeverity

Remarks

Indicates how much practical harm a MimeComplianceViolation is likely to cause, allowing an application to triage compliance issues rather than treating them all equally.

The values are ordered from least to most severe, so they may be compared using the relational operators. For example, issue.Severity >= MimeComplianceSeverity.Major will match everything except Minor violations.

  Note

Severity depends on how the message is being used. A few violations are requirements of the channel a message travels over rather than of the message itself, and are therefore rated lower in Storage than in Transport. See MimeComplianceContext for details.

Members

Minor 0 The violation is technically non-compliant but is tolerated by nearly all software.
Major 1 The violation is likely to cause interoperability problems.
Critical 2 The violation is a known vector for content smuggling.
