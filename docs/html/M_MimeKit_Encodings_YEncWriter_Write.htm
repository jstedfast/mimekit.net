Remarks

Writes framing, payload and a checksum trailer. Leaves the source open and does not flush the destination. The source must end at exactly the declared decoded size; size errors invalidate the output. A supplied whole-file checksum for a partial range is emitted without verification.

Exceptions

ArgumentNullException header or source is null.
ArgumentException A stream, filename encoding or header is invalid.
ArgumentOutOfRangeException The header exceeds the configured limits or the writer's line-length range of 60 through 998.
FormatException The source size or supplied checksum does not match.
InvalidOperationException The writer has faulted.
ObjectDisposedException The writer is disposed.
OperationCanceledException The operation was canceled.
IOException An I/O error occurred.
