public enum HtmlComplianceViolation

Remarks

An enumeration of the parse errors defined by the tokenization section of the HTML Living Standard, as reported to an IHtmlComplianceLogger.

Parse errors that describe the input stream itself (such as control characters, noncharacters and surrogates that appear literally in the text) are not reported.

A handful of members do not describe a defect in the document at all, but rather a limit that the document exceeded. They are reported the same way so that a consumer can tell that some of the content was not processed.
