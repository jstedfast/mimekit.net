Remarks

A MIME parser is used to parse MimeMessage and MimeEntity objects from arbitrary streams.

The parser is built on top of a MimeReader, and the protected On* methods mirror the MimeReader callbacks so that subclasses can observe the parsing process (for example, to record the stream offsets of each entity). Overrides must call the base implementation or the parser will not be able to construct the resulting MimeMessage or MimeEntity.
