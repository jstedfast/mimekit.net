public enum SmtpUtf8AddressError

Remarks

The reason that an address failed validation by the SmtpUtf8AddressValidator.

When an address violates more than one rule, the first violation found is reported. The rules are checked in the order that they are declared in this enum.

Members

None 0 The address is valid.
Syntax 1 The address does not match the Mailbox syntax defined in rfc5321 as extended by rfc6531.
LocalPartTooLong 2 The local-part exceeds 64 octets when encoded in UTF-8.
LabelTooLong 3 A label in the domain exceeds 63 octets when encoded as an A-label.
DomainTooLong 4 The domain exceeds 253 octets when each of its labels is encoded as an A-label.
AddressTooLong 5 The address exceeds 254 octets when encoded in UTF-8.
ALabel 6 An atom in the local-part or a label in the domain begins with the ACE prefix (xn--).
DisallowedCodePoint 7 The address contains a code point that is not permitted by the PRECIS IdentifierClass (rfc8264) and is not U+0020 SPACE.
NotNormalized 8 The address is not in Unicode Normalization Form C (NFC), as defined by Unicode Standard Annex #15.
ContextRule 9 The address contains a code point that is only permitted in certain contexts (such as U+200D ZERO WIDTH JOINER or U+00B7 MIDDLE DOT) and the context rule defined in rfc5892 is not satisfied.
MixedScripts 10 The address contains code points from more than one non-ASCII script. Han, Hiragana and Katakana count as a single script, as do Han and Hangul, and Han and Bopomofo.
