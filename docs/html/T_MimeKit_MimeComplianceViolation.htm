MimeComplianceViolation Enumeration

An enumeration of potential MIME compliance violations.

public enum MimeComplianceViolation

Remarks

An enumeration of the ways in which a message may deviate from the Internet Message Format and MIME specifications, as reported to an IMimeComplianceLogger by MimeReader.

  Note

The UUEncode and UUEncoded spellings are deliberately distinct: UUEncode names a construct belonging to the uuencode format itself (the pretext, the file mode within the begin marker, the end marker) while UUEncoded names the encoded data.
